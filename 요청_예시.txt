Banana Loop · 복사해서 쓰는 요청 예시

[작업 폴더 경로]와 대괄호 안의 내용만 바꿔서 에이전트 채팅에 보내세요.
아래 문장들은 채팅용입니다. 브라우저 콘솔에는 완성된 JS 파일만 넣습니다.

1. 스킬과 이미지·기획서를 처음 전달할 때

[작업 폴더 경로] 안의 banana-loop/SKILL.md를 먼저 읽어줘.
이미지와 기획서·시놉시스를 확인하고, 어떤 자료가 있는지와
가능한 작업 방식을 간단히 안내해줘. 읽지 못한 자료가 있으면 알려줘.
내가 원하는 건 [배경마다 시간대가 다른 이미지 3가지]야.
원본은 보존하고, 실행 파일 하나와 내가 할 일만 짧게 알려줘.

2. 우선 자료 정리만 할 때

이 폴더의 스킬을 읽고 이미지와 시놉시스를 확인해줘.
작업 순서를 정하고, 원본은 그대로 둔 채 정리된_레퍼 폴더에
01_이름, 02_이름처럼 번호를 붙여 복사해줘. 확장자는 유지해줘.
원본 이름 → 새 이름 → 순서의 이유를 짧게 보여줘.
우선 폴더 정리까지만 해줘.

3. 텍스트만으로 만들 때

스킬을 사용해서 [안개 낀 숲] 이미지 4개를 만들 실행 파일을 준비해줘.
레퍼 없이 프롬프트만 순서대로 넣어줘.
[같은 장소와 카메라 구도]는 유지하고 [시간대]만 다르게 해줘.
무한 반복과 셔플은 끄고, 화면비와 출력 수는 사이트 설정을 그대로 써줘.

4. 캐릭터 한 장으로 의상·헤어를 바꿀 때

스킬을 사용해서 01번 캐릭터 원본으로 의상 3가지와 헤어 3가지를 준비해줘.
얼굴·체형·그림체는 유지하고 매번 같은 원본을 써줘.
의상 테스트는 헤어를, 헤어 테스트는 의상을 그대로 유지해줘.
먼저 의상 1장과 헤어 1장, 총 두 요청만 테스트할 실행 파일을 줘.
한 이미지에 캐릭터 한 명, 같은 배경의 정면 전신으로 해줘.

캐릭터시트가 필요할 때만 덧붙이기:
“이번에는 캐릭터시트로 해줘. 왼쪽 얼굴 클로즈업, 가운데 정면 전신,
오른쪽 후면 전신을 기본 구성으로 잡아줘.”

5. 여러 이미지를 폴더에서 순서대로 바꿀 때

스킬을 사용해서 정리된_레퍼의 01번과 02번으로 테스트를 준비해줘.
01번 원본으로 [오전·저녁] 프롬프트 2개를 먼저 처리하고,
기존 레퍼를 지운 뒤 02번 원본으로 같은 방식의 2개를 처리해줘.
이미지 합성 없이 원본 한 장씩 사용해줘.
파일 선택은 연결한 폴더에서 자동으로 하고, 첨부 목록도 자동으로 닫아줘.
무한 반복·셔플은 OFF, 모델·화면비·출력 수는 사이트 설정 그대로.
프롬프트가 내장된 콘솔 실행 파일 하나와 연결할 폴더 위치를 알려줘.

6. 테스트가 잘 됐을 때

테스트 결과는 괜찮아. 같은 방식으로 [이미지별 5개씩] 준비해줘.
이미 접수한 항목은 [항목 이름]이니 새 실행 목록에서 제외해줘.
기존 스킬의 공통 엔진으로 빌드하고, 사용할 최신 파일 하나를 알려줘.

7. 오류가 났을 때

[버전]에서 [버튼 이름]을 누른 뒤 [오류 문구]가 떴어.
현재 [이미지 번호 / 프롬프트 진행 위치]이고, 브라우저는 [이름]이야.
진단 파일과 입력창·패널 화면을 첨부할게.
실제 화면과 실행 파일을 대조해서 원인부터 확인해줘.
이미 접수된 요청을 반복하지 않게, 기존 스킬을 수정해줘.

진단 저장 위치: 패널 → 진행 기록 · 진단 → 진단 저장.
에이전트에게 보낼 때 파일명·프로젝트 이름에 공유하면 안 되는 정보가 없는지 확인하세요.
