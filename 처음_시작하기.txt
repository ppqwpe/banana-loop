Banana Loop · 간단 사용 안내

1. 자료를 전달하세요.
스킬 폴더 전체와 필요한 자료를 에이전트에게 주고, 스킬을 먼저 읽게 하세요.

2. 원하는 작업을 말하세요.
작업 준비가 끝나면 콘솔에 붙여넣을 실행 파일을 만들어 달라고 하세요.
텍스트 생성 / 레퍼 한 장 유지 / 여러 레퍼 순차 교체를 지원합니다.

3. 실행 파일을 붙여넣으세요.
Higgsfield에서 모델·화면비·출력 수를 설정하세요.
콘솔에_붙여넣기.js를 메모장으로 열어 전체 복사하세요.
F12 → Console → 붙여넣기 → Enter.
차단 경고가 뜰 때만 코드를 확인하고 allow pasting을 직접 입력하세요.

4. 테스트 후 실행하세요.
여러 레퍼를 쓸 때는 이미지 폴더를 연결하세요.
한 번 테스트로 확인한 뒤 이어서 실행하세요.
접기는 실행 유지, 중단·닫기는 추가 요청 중단입니다.

알아두세요
· Windows Chrome / Nano Banana Pro에서 확인한 알파 버전입니다.
· 파일 읽기·코드 실행이 가능한 에이전트와 Unlimited 이용 권한이 필요합니다.
· 탭을 열어두고 컴퓨터 절전을 꺼두세요. 새로고침 후 자동 재개는 안 됩니다.
· 접수와 완성은 다릅니다. 여러 레퍼 동시 합성·자동 다운로드는 지원하지 않습니다.
· 오류가 나면 진행 기록 · 진단에서 저장하고 화면과 함께 에이전트에게 보내세요.
